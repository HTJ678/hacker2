# 假的 Windows 安全中心 · 整蛊网页

一个纯前端的玩笑页面：点开之后会假装系统被入侵——蓝屏、警报音、满屏滚动的命令行，最后自己恢复。

**没有联网、没有请求后端、不读写任何本地数据**，所有效果都是 CSS + Web Audio 现场生成的，刷新就没事。适合拿同学开玩笑，不适合拿去吓人。

## 玩法

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge，需要允许声音播放）。

也可以当 JSP 页面丢进 JavaWeb 项目里跑，原始文件保留了 JSP 指令。

## 提示

- 全屏 + 声音，建议先自己看一遍再给别人看
- 请在别人知道「这是玩笑」的前提下使用，别对着不熟的人放
- 没有恶意代码，可以自己读源码验证
